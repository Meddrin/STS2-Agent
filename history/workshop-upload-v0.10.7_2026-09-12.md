## Changes in this upload (relative to v0.10.6 on the Workshop)

See the v0.10.7 section of [CHANGELOG.md](../CHANGELOG.md). The three that players notice directly:

1. **Leaving a run stops auto-play** (previously a boundary reset inside the loop meant this check never fired, so after the player returned to the main menu the AI kept operating in the menu).
2. **Starting auto-play in solo mode no longer shows "you can invite an AI teammate"**, and while running it shows "teammate is acting" instead of always showing "requesting model".
3. **Proactive speech no longer goes permanently silent after 6 messages** (the quota is now reissued each time auto-play starts).

## Process notes (to reuse next time)

1. **The first upload after restarting Steam still fails**: uploading immediately after the restart stalled in `k_EItemUpdateStatusPreparingContent` for about 60 seconds, then failed with `k_EResultFail`. After enabling the local proxy (127.0.0.1:10808), rerunning the same command succeeded on the first try (about 25 seconds through PreparingContent -> UploadingContent -> UploadingPreviewFile -> CommittingChanges).
2. **The upload must run in a detached process**: during the Steam handshake `ModUploader.exe` is sensitive to the parent process lifetime; started with a foreground `&`, it fails outright when interrupted by polling (the 21:19 attempt failed this way). Starting it in the background with `Start-Process -WindowStyle Hidden` and then polling the log file completed reliably.
3. The log is at `%LOCALAPPDATA%/sts2-mod-uploader/win-x64/mod-uploader.log`; it is cleared before each upload, so `-Tail` shows stage progress directly.
