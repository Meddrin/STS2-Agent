## Changes in This Upload (relative to v0.11.0 on the Workshop)

See the v0.12.0 section of [CHANGELOG.md](../CHANGELOG.md). The three that players notice directly:

1. **An unfinished co-op run can be continued**: the main menu shows "Continue AI Teammate", which loads the save and brings the local teammate back (#83).
2. **You can choose the teammate's character**: with `CompanionAutoSelectCharacter=false` the teammate waits at character select for you and does not count against the 5-minute launch budget (#84).
3. **State trustworthiness cleanup**: the reward overlay is correctly named `REWARD`, the card view screen has its own name, an out-of-range index no longer silently clicks the wrong card, and game-side waits all have deadlines.

## Upload Process (reusable)

This matches the pattern recorded for v0.11.0, but there was **only one failed retry**, and the retry completed instantly:

1. Close the game (the game was not running this time), and restart Steam gracefully (`steam.exe -shutdown` -> wait for exit -> launch).
2. Launch `ModUploader.exe upload -w <workspace> -i 3796486050` detached with `Start-Process -WindowStyle Hidden -PassThru`, with stdout/stderr redirected to `%TEMP%`.
3. Attempt 1: started 02:08:03 -> failed 02:24:44 (`Failed to download manifest "steampipe-partner.akamaized.net/…" (timeout)`), the same root cause as the v0.11.0 run: the Steam client timed out on the Akamai domain while fetching the item's current manifest.
4. Attempt 2: started 02:24:54 -> **upload completed 02:25:01** (`Uploaded new content ( ManifestID 3382317012139913714 )`) -> 02:25:02 `Upload finished for workshop item 3796486050 : OK`.
5. Re-check: the Steam Web API `GetPublishedFileDetails` was used to verify `file_size` / `time_updated` / `visibility` / `tags`, which equal the local content byte sum exactly.
