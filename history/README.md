# History Archive

This directory holds old plans, phase snapshots, and historical acceptance checklists. Wording such as "current", "to do", and "next step", as well as approval requirements and release conclusions, belongs to the time of the original record and does not automatically become a current task or rule.

The single entry point for current status: [PRODUCT_PLAN_CURRENT.md](../PRODUCT_PLAN_CURRENT.md). The current release entry point: [release readiness](../docs/release-readiness.md).

Cross-version build fingerprints (how many times a version number shipped and how to tell the builds apart): [build fingerprint index](build-fingerprints.md).
