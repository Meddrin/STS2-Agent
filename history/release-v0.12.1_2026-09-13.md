## Changes in This Upload (relative to v0.12.0 on the Workshop)

See the v0.12.1 section of [CHANGELOG.md](../CHANGELOG.md). This version is about the pause boundary:

1. **The pause menu is no longer treated as an "open capstone"**: its option list used to include "Abandon".
2. **Settings / Compendium / Card Library / Relic Collection / Potion Lab / Character Stats / History, entered from the pause menu, each report their real screen name**, no longer report the room underneath, and no longer surface control names such as `Hitbox` as options; `choose_capstone_option` returns 409 on all of these screens.
3. **These pages have a back action again** (`close_main_menu_submenu` goes up one level), while **the pause page itself can never be closed**.
4. **A wrong `--clientId` no longer destroys the co-op save** (`players[].net_id` is compared before loading the save).
